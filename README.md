# Microservicio Capacidad

Gestión de capacidades técnicas del sistema.

## Requisitos

- Java 25+
- MySQL 8.0+
- Gradle 9.3.0+

## Levantar el servicio

```bash
./gradlew bootRun
```

El servicio estará disponible en `http://localhost:8083`

**OpenAPI (Swagger):** `http://localhost:8083/swagger-ui.html`
